1. Executive Summary & Abstract

This project provides an end-to-end mathematical derivation, Python implementation, and empirical verification of an academic Student Marks Prediction System using the Ordinary Least Squares (OLS) regression method. The objective is to predict students' comprehensive Final Examination Marks (0 to 100) from four continuous academic indicators: Study Hours (x1), Attendance Percentage (x2), Assignment Marks (x3), and Internal Assessment Marks (x4).

The machine learning algorithm is built from scratch using pure NumPy, utilizing the analytical Normal Equations:

X^T X w = X^T t ==> w = solve(X^T X, X^T t)

High-level machine learning libraries (such as Scikit-Learn's LinearRegression) were strictly prohibited for model fitting. Scikit-Learn was utilized solely for the initial 80/20 train/test partition and for cross-verifying the accuracy of the manual implementation. On an independent, unseen test set (N=40), the model achieved an R^2 Score of 0.9413 and a Mean Squared Error (MSE) of 16.6786 (RMSE = 4.08 marks), matching Scikit-Learn to 0.000000 difference.

2. Problem Statement & Motivation

Problem Formulation: Given an academic training dataset of N=160 student profiles, where each student is characterized by a 4-dimensional continuous feature vector x_n = [x_n1, x_n2, x_n3, x_n4]^T and a continuous target mark t_n in [0, 100], construct an optimal 5-dimensional parameter vector w* = [w0, w1, w2, w3, w4]^T by minimizing the Sum-of-Squares Error.

Motivation: Early identification of academic vulnerabilities allows university mentors to provide targeted interventions. Furthermore, Ordinary Least Squares serves as the fundamental cornerstone of modern regression theory, providing full mathematical transparency and coefficient interpretability.

5. Mathematical Formulation & Normal Equations Derivation

We model final marks y_hat as an affine combination of input features:

y_hat(x, w) = w0 + w1*x1 + w2*x2 + w3*x3 + w4*x4 = w^T x

To estimate the intercept w0, we augment the input vector with a dummy constant x0 = 1, forming the Design Matrix X in R^(160 x 5):

X = [ 1 x11 x12 x13 x14 ]
[ 1 x21 x22 x23 x24 ]
[ : : : : : ]
[ 1 xN1 xN2 xN3 xN4 ]

The Sum-of-Squares Error objective function to minimize is:

E(w) = 0.5 * ||X*w - t||^2 = 0.5 * (w^T X^T X w - 2 t^T X w + t^T t)

Taking the gradient with respect to w and setting to zero:

grad E(w) = X^T X w - X^T t = 0 ==> X^T X w = X^T t
Computational Linear Algebra Insight: In computational practice, the weight vector is never computed via explicit matrix inversion np.linalg.inv(XtX), which is numerically unstable. Instead, our solver uses np.linalg.solve(XtX, Xty) based on LU/Cholesky factorization.

8. Viva Voce Revision Guide (Key Examination Queries)

Q1: Why is this problem Regression rather than Classification?
A: The target variable (Final Examination Marks) is continuous numerical data spanning [0, 100]. Classification is reserved for discrete categorical labels.

Q2: Why prepend a column of ones to the Design Matrix?
A: It allows the bias/intercept w0 to be estimated as an intrinsic element of the vector dot product w^T x. Without it, the regression hyperplane would pass through the origin (0,0,0,0,0).

Q3: How does Maximum Likelihood Estimation relate to Least Squares?
A: Under an assumption of independent, identically distributed Gaussian noise epsilon ~ N(0, sigma^2), maximizing log-likelihood simplifies directly to minimizing the sum-of-squares error.

Q4: Why use np.linalg.solve() instead of np.linalg.inv()?
A: Matrix inversion has high condition number sensitivity and O(D^3) computational cost. np.linalg.solve uses LU/Cholesky factorization which is numerically stable and avoids inverting ill-conditioned matrices.
